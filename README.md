# Домашняя работа по теме "Тестирование"

## *Описание*

Домашка содержит модули для обработки банковских счетов и карт.

## *Использование*

- Модуль ```masks.py``` запускается через консоль ```python src\masks.py```
1. Функция ```get_mask_card_number``` возвращает замаскированный номер карты.
2. Функция ```get_mask_account``` возвращает замаскированный номер счета.

- Модуль ```processing.py``` запускается через консоль ```python src\processing.py```
1. Функция ```filter_by_state``` возвращает словарь по ключу ```state```.
2. Функция ```sort_by_date``` возвращает отсортированный список по дате.

- Модуль ```widget.py``` запускается через консоль ```python src\widget.py```
1. Функция ```mask_account_card``` определяет функцию для возврата карты или счета.
2. Функция ```get_date``` конвертирует дату операции в привычный вид.

## *Тестирование*
Все необходимые тесты хранятся в директории ```tests```. Покрытие тестами 100 %.
Выполнено 21 тест через ```pytest```
